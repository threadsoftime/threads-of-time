# Threads of Time — Operator Install Guide

**Version:** 1.0.0  
**Deploy stack:** podman Quadlet (systemd) or docker/podman-compose

---

## Prerequisites

| Requirement | Minimum | Recommended |
|---|---|---|
| OS | Linux x86_64 | Linux x86_64 |
| Container runtime | podman 4+ or docker 24+ | podman 4+ |
| CPU | 4 cores | 8 cores |
| RAM | 8 GB | 16 GB |
| Disk (OS + data) | 20 GB free | 50 GB free |
| Database | MySQL 8.x (bundled in the stack) | MySQL 8.4 |
| LLM | Any OpenAI-compatible endpoint | See `docs/byollm-setup.md` |
| GPU on host | Not required | Not required |

**mod-playerbots:** The pre-built GHCR images bake the mod-playerbots SQL into the
`db-import` image. You do **not** need to clone mod-playerbots separately unless
you are doing a source build. Source-build operators: clone the commit pinned in
`UPSTREAMS.toml [playerbots-dependency]` into `modules/mod-playerbots/`.

---

## One-command install

```sh
curl -fsSL https://github.com/threadsoftime/threads-of-time/releases/download/v1.0.0/install-tot.sh | sh
```

The script runs 7 steps and prompts for:

1. Container engine detection (podman or docker — auto-detected, no prompt).
2. mod-playerbots check (informational only; no prompt for pre-built image operators).
3. `TOT_HOME` scaffold (default `/opt/tot`; no prompt — override via `TOT_HOME=<path>` env).
4. Secret generation — `MYSQL_ROOT_PASSWORD`, `MYSQL_PASSWORD`, `HARNESS_BEARER_TOKEN`
   are randomised automatically; no prompt.
5. Image pull (`:1.0.0` from GHCR).
6. **Three interactive prompts:**
   - Realm hostname/IP players put in `realmlist.wtf` (e.g. `realm.example.com`).
   - LLM endpoint URL (press Enter to skip and configure later in `.env`).
   - Deploy mode: `compose` (default) or `quadlet`.
7. Final instructions printed.

After install completes, follow the "First start + GM account" section below.

## Manual install

Download `tot-1.0.0-stack.tar.gz` from the GitHub Release, extract it, and follow
these steps:

```sh
# Extract stack assets
tar xzf tot-1.0.0-stack.tar.gz
mkdir -p /opt/tot
cp -r tot/deploy/* /opt/tot/
cp .env.example /opt/tot/.env

# Edit the env file
$EDITOR /opt/tot/.env

# Pull images
podman pull ghcr.io/threadsoftime/worldserver:1.0.0
podman pull ghcr.io/threadsoftime/authserver:1.0.0
podman pull ghcr.io/threadsoftime/db-import:1.0.0
podman pull ghcr.io/threadsoftime/harness:1.0.0
podman pull ghcr.io/threadsoftime/brain:1.0.0
podman pull ghcr.io/threadsoftime/memory:1.0.0

# Start
TOT_HOME=/opt/tot tot up
```

## `.env` walkthrough

The full env surface is documented in `tot/deploy/.env.example`. Key variables:

| Variable | Purpose |
|---|---|
| `TOT_REALM_HOST` | Public hostname or IP players put in their `realmlist.wtf`. Must be reachable from player machines on port `8085`. |
| `BRAIN_LLM_URL` | OpenAI-compatible chat endpoint (e.g. `http://192.168.1.50:11434/v1`). See `docs/byollm-setup.md`. |
| `BRAIN_LLM_MODEL` | Chat model name (e.g. `qwen2.5:14b-instruct`). |
| `BRAIN_EMBEDDINGS_URL` | OpenAI-compatible embeddings endpoint. May be the same server as `BRAIN_LLM_URL`. |
| `TOT_BOT_POPULATION` | Total bot count spawned in the world (default 20). |
| `TOT_LIVING_BOT_COUNT` | Brain-driven subset of `TOT_BOT_POPULATION` that receive full AI decisions (range 5–15; default 10). |
| `MYSQL_ROOT_PASSWORD` | MySQL root password — generated by `install-tot.sh`. |
| `MYSQL_PASSWORD` | `acore` application account password — generated by `install-tot.sh`. |
| `HARNESS_BEARER_TOKEN` | Bearer token for the harness MCP/HTTP API — generated by `install-tot.sh`. |

All variables are loaded into containers at runtime via `EnvironmentFile`. Secrets
never appear in image layers.

## First start + GM account

Start the stack:

```sh
TOT_HOME=/opt/tot tot up
```

Watch the firstboot init container:

```sh
tot logs firstboot
```

Wait until you see `[firstboot] bootstrap complete.` — this confirms AC schema,
module SQL, ToT content SQL, and the realm row have all been applied. If firstboot
fails it prints `STEP FAILED: <step>` and exits non-zero. See
`docs/operator-troubleshooting.md` for the recovery procedure.

**Create the GM account** once worldserver is fully up:

```sh
TOT_HOME=/opt/tot tot run-console "account create admin <password>"
TOT_HOME=/opt/tot tot run-console "account set gmlevel admin 3 -1"
```

Replace `<password>` with a strong password. The firstboot container does not seed
SRP6 credentials automatically — this console step is required on first boot.

**Firewall:** open ports `3724` (auth) and `8085` (world) for players. Open `8099`
(harness) only if you need remote brain/MCP access; it is not required for
gameplay.

## Verifying a healthy boot

```sh
# Worldserver fully loaded:
tot logs worldserver | grep "World initialized"

# Harness daemon live (replace <token> with HARNESS_BEARER_TOKEN from .env):
curl -s -H "Authorization: Bearer <token>" http://127.0.0.1:8099/v1/tools/obs.ping
# Expected: {"ok":true,"result":{"pong":true}}
```

If `obs.ping` returns a non-200 response, check `tot logs harness` for startup
errors and confirm the worldserver is fully initialized first (harness connects
to the worldserver socket on startup).

## Player install

Player setup is documented in [`docs/player-install.md`](player-install.md).

Summary:

1. Download `patch-ZZ-tot-1.0.0.MPQ` from the GitHub Release.
2. Rename it exactly to `patch-ZZ.MPQ` and place it in your WoW `Data/` directory.
3. Edit `WoW/Data/enUS/realmlist.wtf`: set `realmlist <TOT_REALM_HOST>`.
4. Clear `Cache/WDB/enUS/itemcache.wdb` if you have played on the client before
   with a different patch configuration.
5. Launch `WoW.exe`. The login screen should display the ToT patch disclaimer.

Full details including error troubleshooting: [`docs/player-install.md`](player-install.md).
